🔍 PR Review Guide

Atriis Test Automation · Playwright + Cucumber BDD · quick visual reference

⭐ The one rule that catches most problems

Code flows DOWN only. Never skip a layer, never go back up.

Feature→ Steps→ DSL→ Page Objects→ Playwright
STOP — do not merge until fixed

1 · A step reaches into a Page Object (layer skip)

❌ Don't
When('I click the flight tab', async function () {
  const p = new FlightSearchPage(this.page);
  await p.clickFlightTab();
});
✅ Do
When('I open the flight search', async function () {
  await FlightSearch.openFlightSearch(this.page);
});

Steps only ever call DSL (@dsl) — never Page Objects, never Playwright.

2 · Arrow function in a step (breaks this.page)

❌ Don't
When('I search', async () => {
  await FlightSearch.search(this.page); // undefined!
});
✅ Do
When('I search from {string}', async function (route) {
  await FlightSearch.searchFlightOneWay(this.page, route);
});

3 · DSL talks to the browser directly

❌ Don't
const Search = {
  async fillFrom(page, value) {
    await page.locator('#from').fill(value);
  },
};
✅ Do
const Search = {
  async fillFrom(page, value) {
    if (!page) throw new Error('page is required');
    const sp = getPageObject(page, SearchPage);
    await sp.fillInFromField(value);
  },
};

DSL composes Page Object methods. (Only waitForLoadState / commented waitForTimeout allowed.)

4 · DSL written as a class

❌ Don't
class FlightSearch {
  constructor(page) { this.page = page; }
  async search() { ... }
}
✅ Do
const FlightSearch = {
  async searchFlight(page, route) {
    return { searched: true, route };
  },
};

Object literal, page always first, returns an object (never just true).

5 · Domain safety — this costs real money 💸

❌ Don't
Scenario: Book Amadeus flight
  When I book a flight LON→NYC
  Then booking is confirmed
  # no cancellation = live PNR!
✅ Do
Scenario: Book Amadeus flight
  When I book a flight LON→NYC
  Then booking is confirmed
  And I cancel the trip

Always cancel GDS flights. Always filter refundable before selecting a hotel room — never book non-refundable.

6 · Don't reinvent — reuse exists

❌ Don't
async clickOneWay(page) { ... }
async clickRoundTrip(page) { ... }
✅ Do
async selectTripType(page, tripType) { ... }

Before approving any new step / DSL method / selector, search the repo for one that already does it.

FIX BEFORE MERGE — important

Logging, selectors & waits

❌ Don't
console.log('searching');
await page.locator('button.submit').click();
await page.waitForTimeout(5000);
✅ Do
logger.info('Searching', { route });
await page.locator(SELECTORS.SUBMIT).click({ timeout: 10000 });
await spinner.waitFor({ state: 'hidden', timeout: 15000 });

No console.log. No inline selectors (use SELECTORS). No bare sleeps — wait for a condition.

Feature files read like user stories

❌ Don't
Scenario: search
  When I click the locator for "from"
  and type "LON"
✅ Do
@regression @priority:critical @provider:amadeus
Scenario: Search a one-way flight
  When I search for a one way flight from "LON-NYC"
  Then I see available flight results

Tagged · parameterized ({string}/{int}) · no technical jargon · @provider:* matches the real supplier.

NICE TO HAVE — non-blocking

Clearer names · richer error messages (what failed + actual + expected) · simpler logic · extra logging context. Note them, but they don't block the merge.

⚡ 30-second triage

  • No layer skips (Feature→Steps→DSL→Pages→Playwright)
  • Steps use function, not =>; import only from @dsl
  • DSL is an object literal, page first, inputs validated, returns objects
  • No new code duplicating existing steps/DSL/selectors
  • GDS flights cancelled · hotels filtered refundable before booking
  • @provider:* tag matches the supplier flow used
  • No console.log, no inline selectors, no unjustified waitForTimeout
  • Feature reads like a user story, tagged, parameterized
  • New DSL file added to src/dsl/index.js
⚖️ Any 🔴 or 🟡 finding = do NOT merge until fixed. Only 🟢 = good to go.
